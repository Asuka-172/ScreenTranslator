# ScreenTranslator 屏幕翻译器

一个 Windows 桌面屏幕翻译工具：**框选屏幕区域 → OCR 识别文字 → 自动翻译**，结果实时显示在悬浮窗口的历史记录中。支持翻译朗读、全局热键、多主题、插件引擎等扩展能力。

## 功能特性

- **屏幕截图识别**：按 `F1` 进入截图模式，拖拽框选任意屏幕区域，自动识别其中的文字
- **OCR 文字识别**：基于 Tesseract，支持中英文（`eng+chi_sim`），带 OpenCV 图像预处理增强识别率
- **自动翻译**：默认调用免费的 Google 翻译接口，支持自动检测源语言
- **多翻译源切换**：Google / 自定义在线引擎（URL + API key）/ 插件引擎 / 离线本地词典，统一接口、可在设置页动态切换并「测试翻译」
- **翻译缓存与回退**：内存缓存避免重复请求；在线引擎失败时可自动回退到离线引擎
- **离线翻译（本地词典）**：绿色免安装，读取本地词典文件逐词/短语替换，可作断网时的降级方案
- **翻译朗读（TTS）**：基于 Windows SAPI，翻译完成后自动朗读，语速/音量可调
- **全局热键**：系统级热键（窗口失焦也能触发），`F1`/`F2`/`F4` 可自定义，另支持「显示/隐藏窗口」「朗读最近一条」
- **主题系统**：深色 / 浅色 / 高对比度三套主题，字体、字号、窗口透明度可调
- **插件系统**：`IPlugin` 接口 + `QLibrary` 动态加载 `.dll`，内置百度翻译示例插件
- **历史记录与导出**：悬浮窗展示翻译历史，底部按钮导出为 `.txt` 或 `.docx`
- **文档翻译**：导入 `.pdf` / `.docx` / `.txt` 整篇文档，逐段翻译并导出为 `.docx` / `.pdf` / `.txt`，保留标题层级与加粗/斜体
- **长文分段翻译**：整篇预分段（单请求默认 ≤ 6000 字节，超长段落按句/词边界自动切块），多路并发按原文顺序分批提交，每批译文**接续写入同一个译文文件**（txt/docx/pdf，文件中始终包含已提交前缀，即半成品）
- **断点续传**：每完成一段落盘 checkpoint，失败/取消/崩溃后重新导入同一文件可继续翻译，无需从头再来
- **失败重试与限流**：可重试错误（限流 52001/54003/54005、网络超时、429/502/503 等）指数退避自动重试；可配置请求最小间隔适配百度 1 QPS

## 使用说明

| 操作 | 快捷键/方式 |
|------|------------|
| 截图翻译 | `F1` |
| 语言设置 | `F2` |
| 打开设置 | `F4` |
| 取消截图 | `Esc` |
| 导出记录 | 窗口底部按钮（.txt / .docx） |
| 文档翻译 | 底部「导入文件」按钮或右键菜单「导入文档翻译」 |
| 复制/清空/设置/退出 | 窗口内右键菜单 |

所有热键可在设置页「全局热键」中自定义；主题、字体、透明度、TTS 等在设置页调整后即时生效并持久化。

## 技术栈

- **Qt 6**（Widgets / Core / Gui / Network）— GUI 与网络请求
- **OpenCV** — 图像预处理（灰度、锐化、CLAHE、自适应阈值、形态学）
- **Tesseract + Leptonica** — OCR 文字识别
- **Windows SAPI**（COM）— 语音合成（TTS）
- **Windows RegisterHotKey** — 系统级全局热键
- **CURL / nlohmann_json** — 依赖库（插件 HTTP 请求等）
- **poppler / zlib** — PDF 文本提取与 docx（zip 容器）解压

## 插件

插件以动态库形式放在可执行文件同目录（或 `plugins/` 子目录）下，启动时自动加载。

内置的百度翻译示例插件使用百度翻译开放平台的「通用翻译 API」。在设置页「翻译与词典」中切换到「百度翻译」引擎后，会在弹出的配置窗口中填写 **APPID** 与 **密钥**（两者在百度翻译开放平台「开发者信息」页并列显示），保存后自动生效，无需手动设置环境变量。

## 引擎配置

在设置页「翻译与词典」中切换翻译引擎后，会在弹出的独立窗口中完成该引擎的配置：

- **自定义在线引擎**：填写请求 URL 模板（占位符 `{text}`=原文、`{from}`=源语言、`{to}`=目标语言、`{key}`=密钥），密钥可放在 URL 参数或请求头中；结果按 JSON 路径提取（如 `data.translatedText`，留空表示整个响应即译文）。
- **百度翻译**：填写 APPID 与密钥（见上文「插件」一节）。
- **离线翻译（本地词典）**：启用后读取词典文件（默认 `models/glossary.txt`），每行一条 `源词=译文`（`#` 开头为注释），逐词/短语替换。可勾选「回退」让在线引擎失败时自动切到离线。

「翻译与词典」页下方还有「文档翻译（长文）」设置：分块字节上限（默认 6000）、并发路数（默认 3）、失败重试次数（默认 3）、重试基础间隔、请求最小间隔（0=不限，百度标准版建议 1100ms）、断点续传开关。

## 构建

### 依赖

- Visual Studio 2022（MSVC，x64）
- CMake ≥ 3.20
- [vcpkg](https://github.com/microsoft/vcpkg) 及以下包：

```bash
vcpkg install opencv tesseract leptonica curl nlohmann-json zlib poppler --triplet x64-windows
```

- Qt 6（MSVC 2022 版本）

### 编译

项目已提供 `CMakePresets.json`，其中 `toolchainFile` 与 `CMAKE_PREFIX_PATH` 需按本机路径调整：

```bash
cmake --preset default
cmake --build out/build --config Release
```

### 运行前准备

- 将 Tesseract 训练数据（`eng.traineddata`、`chi_sim.traineddata` 等）放入可执行文件同目录下的 `tessdata/` 文件夹。
- TTS 朗读依赖系统语音包（Windows 通常自带中文语音 Huihui）。

## 工作原理

1. 截图区域 → 转 `cv::Mat`
2. 预处理：暗底检测反转 → 1.5 倍放大 → 拉普拉斯锐化 → CLAHE → 中值滤波 → 二值化（Otsu / 自适应高斯两种候选按置信度择优）
3. 后台线程异步 OCR
4. 结果回主线程，经翻译引擎管理器调用当前引擎（Google / 自定义 / 插件 / 离线），缓存命中直接返回，在线失败按配置回退离线
5. 译文追加到历史记录，按配置触发 TTS 朗读
